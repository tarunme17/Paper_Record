Import PDF Statement

Import production records from a PDF purchase/bill statement, then filter before confirming.
A line is recognized as Premium A4 if it mentions "real" + "long", Premium Convent for "real" + "note", Writon A4 for "007" + "long", and Writon Convent for "007" + "note" — or any item name you've set up under Item Setup. Bill number and date are carried forward from each bill's header line to all of its item lines automatically. Lines that don't match one of these (e.g. drawing books, practical books, packing/loose-page entries) are intentionally skipped since they aren't one of the 4 tracked categories.
